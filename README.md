# Homework Bot

Telegram-бот для отслеживания статуса проверки домашних работ в Яндекс Практикуме.

Проект выполнен в рамках учебной работы. В нём реализованы взаимодействие с API Практикума, отправка уведомлений в Telegram, обработка статусов домашних работ, логирование и обработка ошибок.

## Возможности

- опрос API Практикума каждые 10 минут
- получение актуального статуса домашней работы
- отправка уведомлений в Telegram при изменении статуса
- обработка статусов `reviewing`, `approved` и `rejected`
- логирование работы приложения
- отправка уведомлений об ошибках в Telegram
- защита от повторной отправки одинаковой ошибки
- проверка обязательных переменных окружения при запуске

## Технологии

- Python 3.12
- Requests
- pyTelegramBotAPI
- python-dotenv
- logging

## Как работает бот

После запуска бот получает текущую временную метку и обращается к API Практикума.

Если новых статусов нет, бот ждёт 10 минут и выполняет следующий запрос.

Если статус домашней работы изменился, бот формирует сообщение и отправляет его в Telegram.

Поддерживаются следующие статусы:

- `reviewing` — работа взята на проверку
- `approved` — работа успешно прошла ревью
- `rejected` — в работе есть замечания

При возникновении ошибки информация записывается в лог и, если это возможно, отправляется в Telegram. Одинаковая ошибка не отправляется повторно до восстановления нормальной работы приложения.

## Установка и запуск

Клонируйте репозиторий:

```bash
git clone https://github.com/SV-Miki/homework-bot.git
cd homework-bot
```

Создайте и активируйте виртуальное окружение:

```bash
python -m venv venv
source venv/bin/activate
```

Для Windows:

```bash
venv\Scripts\activate
```

Установите зависимости:

```bash
pip install -r requirements.txt
```

Создайте файл `.env` в корне проекта:

```env
PRACTICUM_TOKEN=your-practicum-token
TELEGRAM_TOKEN=your-telegram-bot-token
TELEGRAM_CHAT_ID=your-telegram-chat-id
```

Запустите бота:

```bash
python homework.py
```

## Переменные окружения

`PRACTICUM_TOKEN` — OAuth-токен для доступа к API Практикума

`TELEGRAM_TOKEN` — токен Telegram-бота

`TELEGRAM_CHAT_ID` — идентификатор Telegram-чата для отправки уведомлений
